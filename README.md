A local-first AI knowledge system designed to turn personal information into an intelligent, searchable knowledge base.

Built around the idea of creating a personal system that can store, understand, retrieve, and reason over knowledge.

**Highlights**

- Local LLM integration with Ollama
- RAG-inspired knowledge retrieval
- Hybrid keyword-based retrieval
- OCR-powered knowledge ingestion
- AI-assisted note analysis
- MERN architecture

- Background AI processing
